How Ad Studio works

Advertisement: You provide an image or video URL plus an HTTPS destination. The platform selects eligible campaigns and records a billable impression when a user opens the full-screen ad experience.
Sponsored Task: Your task is published into the existing Tasks → Sponsor Tasks section. Auto Telegram tasks are verified server-side; manual tasks use the existing screenshot review flow.
Escrow: The server validates the budget and reserves Gems before launch. Delivery consumes the reserved advertisement budget; task completion consumes the task reward allocation.
Video: Hosted videos are previewed with a muted player where supported. Failed media loads never block the user interface and the destination remains available.
